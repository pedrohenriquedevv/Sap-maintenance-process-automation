# SAP Maintenance Process Automation Platform

Enterprise process automation solution developed for SAP PM workflows in a Planning and Maintenance Control (PCM) environment.

---

## Project Overview

The project was designed to automate repetitive maintenance order processing activities within SAP PM, reducing manual effort, improving process reliability, and increasing operational efficiency.

The solution integrates Excel VBA with SAP GUI Scripting, allowing automated execution of maintenance workflows that were previously performed manually.

---

## Business Problem

The PCM team was responsible for manually processing maintenance orders, including:

- Order release
- User status transitions
- Labor-hour appropriation
- Validation of operational spreadsheets
- SAP transaction execution

The process was repetitive, time-consuming, and susceptible to human error.

---

## Proposed Solution

A complete automation platform was developed using Excel VBA and SAP GUI Scripting.

The system validates inputs, executes SAP transactions automatically, controls exceptions, manages confirmations, and generates execution logs for auditing and troubleshooting.
